# Releases

Release notes for `web-driver`, one file per tagged version
(`RELEASE-<version>.md`).

Each note groups the changes into **Enhancements**, **Fixes**, and **Migration**,
linking the GitHub issues they resolve. The file for the latest version reflects
the current state of the default branch; older files are kept for history.

- Latest: [RELEASE-1.0.0.md](RELEASE-1.0.0.md)
